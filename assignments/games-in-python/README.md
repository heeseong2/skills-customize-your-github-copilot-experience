# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman game in Python using strings, loops, conditionals, and user input. Students will practice working with hidden words, tracking guessed letters, and managing game state.

## 📝 Tasks

### 🛠️ Create the Game Logic

#### Description
Write a Python program that lets a player guess letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Choose a word randomly from a predefined list of words
- Show the current state of the word using underscores for unrevealed letters, such as `_ _ _ _ _`
- Accept one letter guess at a time from the user
- Reveal correctly guessed letters in the word
- Track and display the number of incorrect guesses remaining
- End the game when the player guesses the full word or runs out of attempts
- Display a clear win or lose message at the end of the game

### 🛠️ Improve the User Experience

#### Description
Add a few small improvements to make the game more interactive and easier to play.

#### Requirements
Completed program should:

- Prevent repeated guesses from being counted again
- Tell the player when a letter has already been guessed
- Show the letters the player has already guessed
- Use simple input/output prompts that are clear and beginner-friendly
- Keep the game loop running until the player chooses to quit or the round ends
